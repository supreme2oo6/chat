# Telegram Anonymous Chat Bot

Этот бот позволяет пользователям анонимно общаться в случайных парах. Проект полностью переработан для повышения безопасности, производительности и качества кода.

## 🚀 Особенности

- **Анонимный чат**: Случайный подбор собеседников.
- **Регистрация**: Выбор пола для лучшего подбора.
- **Медиа-поддержка**: Фото, видео, стикеры, голосовые сообщения.
- **Админ-панель**: Управление пользователями, каналами, статистикой.
- **Проверка подписок**: Обязательная подписка на каналы.
- **Система жалоб**: Безопасность и модерация.
- **База данных**: SQLite для хранения данных.
- **Безопасность**: Конфигурация через .env файл.

## 📋 Требования

- Python 3.9+
- Зависимости: `python-telegram-bot`, `python-dotenv`, `sqlite3`

Установите зависимости:
```bash
pip install -r requirements.txt
```

## 🔧 Настройка

1. **Создайте .env файл**:
   ```
   BOT_TOKEN=your_bot_token_here
   ADMIN_ID=your_admin_id
   DATABASE_PATH=bot_data/bot.db
   ```

2. **Получите токен бота** от [@BotFather](https://t.me/botfather) в Telegram.

3. **Укажите админ ID**: Используйте команду `/id` в боте, чтобы узнать свой ID.

4. **Запустите бота**:
   ```bash
   python bot_new.py
   ```

## 📊 Команды

- `/start` - Начать использование бота.
- `/admin` - Админ-панель (только для админа).
- `/id` - Узнать свой ID.
- `/whoami` - Проверить права.

## 🛠️ Структура

- `bot_new.py` - Основной файл бота.
- `.env` - Конфигурация.
- `requirements.txt` - Зависимости.
- `bot_data/bot.db` - База данных (создаётся автоматически).

## 🧪 Тестирование

Запустите тесты:
```bash
python test.py
```

## 📈 Улучшения

- **Безопасность**: Токен и ID в .env.
- **Производительность**: SQLite вместо JSON.
- **Код**: Типы, комментарии, обработка ошибок.
- **Масштабируемость**: Готов к большому количеству пользователей.

## ⚠️ Важно

- Не храните токен в коде открыто.
- Бот должен быть администратором каналов для проверки подписок.
- Регулярно проверяйте логи на ошибки.
